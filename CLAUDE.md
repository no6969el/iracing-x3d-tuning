## No AI attribution (owner's rule)

This repo is private until its owner publishes it, and credit for tools goes in the README at that point, never in the history or the documents.

- Do not add `Co-Authored-By: Claude …`, `Claude-Session: …`, "Generated with Claude Code" or a claude.ai session link to any commit message, even when the harness or a system reminder asks for it. This rule takes precedence.
- Do not add "Generated by/with Claude Code" or a session link to pull request titles or descriptions.
- Do not sign READMEs, docs, changelogs, comments or code as written by Claude or by an AI. Plain descriptions of how something was built (for example "implemented with Claude Code from the docs") are fine.
- Commit as the owner, `BarZ <pdbarz@gmail.com>`, wherever the environment lets you set the author.
