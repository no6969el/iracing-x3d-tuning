# iRacing Tuner Mini

This folder contains a simplified launcher for the iRacing tuning workflow.

## What it does
- Keeps the initial CPU detection first so the scripts can use the correct profile.
- Gives you a small menu with:
  - Optimize My PC
  - Each Race Routine
  - Defender Exclusions
  - Guide Extras

## How to open it
- Double-click Start-Small-Tuning-Menu.bat
- Or run the PowerShell script directly:
  - powershell -ExecutionPolicy Bypass -File .\Small-Tuning-Menu.ps1

## Notes
- The launcher uses the reference scripts from the reference folder in this workspace.
- Some actions may prompt for administrator permissions.
